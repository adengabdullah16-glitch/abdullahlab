    Pengaturan

    Biarkan openrouter/free agar OpenRouter memilih model gratis yang tersedia, atau tempel ID model berakhiran :free.

    Kode ini membuka ingatan bersama (HP & iPad) dan data bot kesehatan. Kosongkan bila hanya ingin menyimpan di perangkat ini.

    Ganti mode dengan perintah (ucapkan atau ketik): "mode pribadi", "mode santai", "mode tutor". Saat mode Tutor, perintah suara tidak bisa keluar dari Tutor (agar siswa tidak membuka mode pribadi); ketik /pribadi atau /santai untuk keluar.

    API key dan kode rahasia hanya disimpan di browser perangkat ini, tidak ada di kode halaman.
